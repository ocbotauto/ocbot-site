How to connect

  1. Install the app

    Android/iOS: the "ntfy" app (Play Store/App Store), no account needed. Or open web.ntfy.sh in a browser.

  2. Pick a topic name

    A topic is the secret string the bot posts to: e.g. rig-a7f3-2026. Anyone who knows the name can read the notifications and send commands to the bot — avoid common names ("test", "rig"). The setup wizard suggests a random one.

  3. Subscribe to the topic

    In the app: "Subscribe" → enter the topic name. For self-hosted — your own server address (see below).

  4. Connect the bot

    In the setup wizard choose "2) ntfy" and enter the topic name — or in Telegram with OCBot: /notify ntfy https://ntfy.sh/rig-a7f3-2026. If the topic is token-protected, append it: ?token=tk_….

  5. Test the push

    /notify test — a push with the rig name title arrives on the phone.

  6. Type commands into the same topic

    The channel is two-way: send /status as a message into the topic and the answer arrives as the next push. Every bot command works; files (CSV tables, the catalog) are delivered to Telegram only.

Self-hosted ntfy

Full control — host your own ntfy server: any URL accepting a POST to a topic works.

# your server instead of ntfy.sh:
/notify ntfy https://ntfy.my-domain.tld/rig-a7f3-2026

What the message looks like

The push title is the rig name; the body is the same text as in Telegram. Plain text, no images, instant delivery.

A rig can post to one topic or several (multiple channels are allowed — /notify keeps them all). Prefer random names nobody guesses.

FAQ

The push does not arrive

Check: the subscription is active in the app; the URL in /notify ntfy uses exactly the same topic; test with /notify test.

Notifications from strangers

Then the topic name is too simple: anyone who knows it can post. Rename the topic to something random and update /notify ntfy.

Can it work without the app?

Yes: web.ntfy.sh shows the same feed in a browser, but the app is better — a true instant push.

Several phones?

Yes: subscribe any number of devices and browsers to the same topic — everyone gets the push.

Do commands really work in the topic?

Yes: the topic is a chat — type /status and get the answer. The topic name is also the password: whoever knows it can send the bot commands, so keep the name random and long.
