Каталог пресетов

Инструкция по установке и командам →

Лучшие настройки разгона по моделям видеокарт. Данные присылают боты с ригов: только проверенные пресеты, без UUID карт и имён ригов. Страница обновляется сама.

Можно посмотреть и свой файл каталога: перетащите его сюда (бот присылает его по /catalog). На сайте он не сохраняется.

Как получить свой файл каталога

В Telegram: отправьте боту /catalog, он пришлёт файл. Без Telegram, на самом риге:

cd /root/ocbot && python3 -m ocbot --config config.json --catalog-export catalog.json

Чужой файл можно принять в бота: --catalog-import catalog.json или просто отправить файл боту в Telegram. Такие пресеты станут стартовой точкой для карт без своей истории, 2-часовая проверка останется.

Пресет подходит одной модели с той же памятью, майнером и версией. Перед использованием на другом риге его стоит проверить: охлаждение, райзеры и питание отличаются. Бот и пресеты предоставляются «как есть», использование на ваш риск: отказ от ответственности.
