The best overclock settings by GPU model. Data is submitted by bots running on rigs: only verified presets, no card UUIDs or rig names. The page updates itself.

You can also view your own catalog file: drag it here (the bot sends it via /catalog). It isn’t stored on the site.

How to get your own catalog file

In Telegram: send the bot /catalog and it will send you the file. Without Telegram, on the rig itself:

cd /root/ocbot && python3 -m ocbot --config config.json --catalog-export catalog.json

Someone else’s file can be fed back into the bot: --catalog-import catalog.json, or just send the file to the bot in Telegram. Those presets become a starting point for cards with no history of their own; the 2-hour verification still applies.

A preset fits one model with the same memory, miner and version. Before using it on another rig, check it: cooling, risers and power delivery differ. The bot and its presets are provided “as is”, use at your own risk: disclaimer.
