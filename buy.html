Trial period: 3 days

Once per rig. The setup wizard turns it on by itself at the end of installation — nothing extra to run. If the bot was installed without the wizard, or the trial didn't start by itself, run this on the rig:

cd /root/ocbot && python3 -m ocbot --config config.json --trial

The trial runs in “Compromise” mode and accepts the core commands: /status, /card, /stop, /resume, /safe, /table, /psu, /pl, /balance. Mode selection, the “4 parameters”, manual tuning and the catalog unlock with a key.

Trial condition: verified presets are submitted anonymously to the site’s shared catalog (card model, core/mem/PL, hashrate and power draw; no rig name, card UUID or IP). This can’t be turned off during the trial. With a purchased key, submission can be turned off at any time with /share off. Before starting, the bot will ask you to confirm you’ve read the terms and disclaimer.

How to activate a key

Run this on the rig (replace OC-... with your own key):

cd /root/ocbot && python3 -m ocbot --config config.json --activate OC-XXXXX-XXXXX-XXXXX-XXXXX

If the bot is already connected to Telegram, you can do the same right in the chat, no Hive Shell needed: send the bot /activate OC-XXXXX-XXXXX-XXXXX-XXXXX.
