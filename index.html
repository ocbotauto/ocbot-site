Mixed cards in one rig

One setting for every card doesn’t work

A typical case: 3070, 3080 Ti, 3090 and 4070 in one rig. Each has its own core and memory headroom, its own memory chips, its own efficiency. Tuning such a rig by hand takes weeks, and one shared profile either loses hashrate or crashes the weaker cards.

▦

Every card on its own

Its own core, mem and power limit for each card. Settings are tied to the card’s ID, not the slot number, so they don’t get mixed up when cards are moved.

⇄

Power is split smartly

In hashrate mode the bot raises one card’s power limit at the expense of the others, finds each one’s maximum, then picks the best distribution across the whole rig within the PSU’s budget.

◎

A weak card doesn’t drag the rig down

A drop is recorded as a boundary for the exact card that caused it. The rest keep their presets, and the bot leaves that one card some headroom.

How it works

From install to a finished preset

The first search takes time; after that the bot just keeps watch.

  1. Install

    Unpack the archive, run the setup wizard, enter just the bot token — the wizard finds the rest itself.

  2. Search

    The bot varies core, mem and power limit, measures hashrate and power draw, and marks boundaries.

  3. Verify

    The best points run under load for two hours.

  4. Run

    The preset applies itself; a safe profile kicks in on failure.

FAQ

The essentials, briefly

Which cards and systems are supported?

Right now, NVIDIA cards on HiveOS; AMD support is coming. The algorithm and miner are set in the config.

Do I need an external server?

No. The bot runs on the rig itself, data is stored in a local SQLite database. Telegram is only needed for control and reports.

What if the rig drops during the search?

The bot records that point as a boundary, restores a safe profile, and continues with some headroom from it.

Is it safe to update?

Yes. Configs and the database are untouched; the archive is verified before the code is replaced, and a rollback is available if something goes wrong.

Is it safe? What does the bot never do?

Full breakdown — here. In short: the bot never asks for seed phrases or private keys, never connects to wallets, cannot spend anything; payment is manual USDT only — no auto-charges or subscriptions. The build is obfuscated and protected by a license key; integrity is verified before install.
