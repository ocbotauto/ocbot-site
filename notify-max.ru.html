MAX — уведомления и команды для пользователей из РФ

Если Telegram у вашего провайдера ограничен, уведомления и команды рига могут приходить в мессенджер MAX (max.ru). Одно условие: бота в MAX создаёт бизнес-профиль — ИП, юрлицо или самозанятый.

Как подключить

  1. Создайте бизнес-бота MAX

    Зайдите на business.max.ru → раздел «Чат-боты» → создайте бота. Важно: платформа доступна бизнес-профилям — ИП, юрлицу или самозанятому; для обычного аккаунта бота создать не получится. Токен находится в «Чат-боты» → меню ⋮ → «Настройки».

  2. Узнайте chat_id

    В MAX найдите своего бота и напишите ему. Затем у встроенного бота «Узнать ID» спросите ваш ID — это и есть chat_id. В мастере установки ID подхватится сам, вручную вводить не придётся.

  3. Подключите канал

    В мастере установки выберите «3) MAX», либо в Telegram у OCBot отправьте: /notify max ТОКЕН CHAT_ID. Внутри это формат max://<chat_id>?token=<токен>; в списке /notify токен маскируется.

  4. Проверьте

    /notify test — в MAX придёт пробное сообщение с префиксом [имя рига].

Что приходит и как выглядит

Сообщения начинаются с имени рига: в MAX они идут одним потоком — иначе не понять, с какого рига событие. Текст ограничен 4000 символами по API MAX, длинные обрезаются с «…».

У каждого рига свой канал: свой токен или свой chat_id. Отключение — /notify off max; список активных каналов — /notify.

Управление — тоже в MAX

Канал двусторонний: команды (/status, /tune 3, /stop — все те же) пишите прямо боту в MAX, ответы приходят туда же. Единственное ограничение: файлы (CSV-таблицы, каталог пресетов) бот присылает только в Telegram.

MAX официально рекомендует вебхуки и ограничивает long polling, которым пользуется бот, — для личного рига это незаметно: команда выполняется с задержкой в несколько секунд.

Частые вопросы

«не MAX-канал» / ошибка формата

Канал MAX задаётся строго форматом max://<chat_id>?token=<токен>; /notify сам собирает его из двух аргументов. Порядок: сначала токен, потом chat_id.

«в MAX-канале нет chat_id или токена»

Один из аргументов пуст. Токен — длинная строка из business.max.ru, chat_id — число от «Узнать ID».

Сообщения не доходят

Напишите боту в MAX (диалог должен существовать, кнопка «Начать»), затем повторите /notify test. chat_id должен совпадать с тем, что показал «Узнать ID».

Ошибка MAX API / timeout

Разовая проблема на стороне MAX или сети: повторите /notify test позже. Состояние каналов видно в /notify.

Токен увидит кто-то ещё?

Нет: в /notify списке токен маскируется; полностью он лежит только в config.json на самом риге.

Обойтись без бизнес-профиля?

У MAX так устроена платформа: бота создаёт ИП, юрлицо или самозанятый. Если это не ваш случай — берите ntfy (канал без регистраций вообще) или Telegram.

Правила: подключение — /notify …, проверка — /notify test, отключение — /notify off канал; все условия и отказ от ответственности — в инструкции.

Индивидуальный проект: не связан с Hiveon и HiveOS и не спонсируется ими; их названия принадлежат их владельцам.
