How to connect

  1. Create a webhook

    In Discord: right-click the channel → "Edit channel" → "Integrations" → "Webhooks" → "New webhook". Pick the channel and copy the webhook URL.

  2. Connect the channel

    In Telegram with OCBot send: /notify discord URL (URL looks like https://discord.com/api/webhooks/…).

  3. Check it

    /notify test — a message like **rig name**: text appears in the channel.

Message format

One message per event: **rig name**: text, up to ~1900 characters — longer ones are trimmed with "…".

Each rig can have its own webhook (or one shared webhook for several rigs: the rig name in the message tells them apart). Bot control from Discord is NOT available — notifications only. To disable: /notify off discord.

Common problems

  • 404the webhook was deleted or re-created: update the URL with /notify discord
  • connection refusedthe rig's network cannot reach the internet or blocks Discord — the bot retries next cycle
  • No messagescheck /notify (is the channel active?) and /notify test; make sure the webhook points to the right channel
  • Too many messagesthe bot does not spam every tuning point: notifications fire for significant events

FAQ

Can I control the bot from Discord?

No: Discord mirrors notifications only; commands stay in Telegram.

How many webhooks can I use?

As many as you need: each rig has its own /notify, they are independent.

Is the webhook URL secret?

Yes: anyone knowing the URL can post to your channel. Do not publish it; it is masked in /notify lists.
