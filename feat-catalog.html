Preset catalog — best settings per card model

In plain words: the community has built verified presets for specific card models (RTX 3060, 3070 Ti, 4070…) and the bot uses them as a reasonable starting point instead of a from-scratch search.

How it works

  1. What the catalog stores

    Only what helps another owner of the same card: card model and memory type, core/mem/PL, mode, efficiency. No UUIDs, no rig names, no accounts — entries are impersonal.

  2. How to use it

    /catalog 3070 in Telegram: the bot shows the best presets for RTX 3070 (matched by memory type). The console equivalent is --catalog 3070. On the web everything is at ocbot.org/catalog.

  3. How to share

    Exchange via a file: --catalog-export writes your presets to a file, --catalog-import takes them in. Contributing impersonated presets to the shared catalog is voluntary — the catalog_share flag controls it (the wizard asks).

  4. What the catalog does NOT do

    It forces nothing: it is a starting point. Every imported preset still passes your 2-hour verification; only what the card holds firmly is kept.

Model pages

Popular cards get their own catalog pages (RTX 3060 Ti, 3070 Samsung/Micron, 4070 Ti…): identical models with different memory batches accept different values, and the catalog matches by memory type.

Security

The catalog contains no UUIDs, rig names, accounts or other personal data. What exactly is stored — the security page.

FAQ

Will the catalog help an "average" rig?

Yes: presets from a similar model give the search a solid start; your limits remain yours and get refined by verification.

Whose database is it?

The community's: your presets, mine, everyone's — shared on ocbot.org, contributed voluntarily and impersonally.

Will anything of mine leak?

No: no UUIDs, names or accounts; the security page describes it in detail.
